ESTEIRA DE PRODUÇÃO LOCAL (HUMAN-IN-THE-LOOP)

[1. Cron / Evento]  ──>  Dispara rotina no OpenBot local
                             │
[2. Agente Especialista]  ──>  Executa tarefa em sandbox privada
                             │
[3. Artefato Compilado]   ──>  Gera vídeo MP4 + folha de contato (contact sheet)
                             │
[4. Interface de Revisão] ──>  Apresenta resultado no chat local
                             │
[5. Seu OK Obrigatório]   ──>  Apenas você autoriza envio ou publicação

Os 4 Agentes de IA

Configurações testadas com limites claros de contexto, permissões de leitura e templates prontos para o OpenBot.

02 / ESTEIRA

Fábrica Local de Reels

O pipeline completo em Python que compila vídeos verticais a 30 FPS: renderização em canvas 720p, upscale Lanczos para 1080p, áudio neural pt-BR e contact sheet para aprovação rápida.

03 / HARDWARE

Zero Exigência de GPU

Roda em qualquer máquina comum rodando Linux, macOS ou WSL2 com 4GB a 8GB de RAM. Sem necessidade de servidores dedicados.

04 / PRIVACIDADE

Checklist de Blindagem de Credenciais

Padrão obrigatório para isolar arquivos .env, proteger segredos contra vazamentos acidentais em commits e trabalhar com dados estritamente sanitizados sob placeholders fake_xxx.
